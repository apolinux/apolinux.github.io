FAQ

¿Trabajas por proyecto o por horas?

Ambos. Para alcance definido prefiero proyecto cerrado con hitos; para soporte o tareas puntuales, bolsa de horas.

¿Ofreces mantenimiento?

Sí. Actualizaciones, correcciones y mejoras evolutivas tras el lanzamiento, con SLA acordado según criticidad.

¿Quién es dueño del código?

Tú, una vez abonado el proyecto. Entrego repositorio y documentación para que tu equipo pueda continuar si lo desea.

¿Qué necesito para empezar?

Una descripción del problema, ejemplos de lo que te gusta (como las demos de este sitio) y disponibilidad para 1–2 reuniones de alineación.
